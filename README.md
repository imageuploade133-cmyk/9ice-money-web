# 9iceMoney - Personal & Business Banking Landing Page

A responsive landing page for **9iceMoney**, featuring personal and business banking solutions, high-fidelity hardware mockups, product showcase cards, custom branded scrollbars, and smooth scroll reveal animations.

## Key Features

- **Componentized Structure**: Modular layout sections including Navigation, Hero, 3-Card Product Showcase (Mastercard, Smart POS, Mobile App), App Download Showcase, and Footer.
- **Scroll Reveal Animations**: Smooth `IntersectionObserver` scroll animations (`.reveal-on-scroll`) with stagger delays and `@media (prefers-reduced-motion: reduce)` accessibility support.
- **Top Navigation Bar**: Brand logo, navigation links, and primary CTA ("Get app").
- **Custom Scrollbar**: Thin custom webkit and Firefox scrollbar styled with project theme colors (`#ffdc55` and `#2526bd`).
